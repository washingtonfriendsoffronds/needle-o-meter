# Needle-o-Meter

How far you are from the Space Needle in Seattle, and whether you're above or below it. Completely useless. Very precise.

- Live GPS distance and direction to the Space Needle (47.6205° N, 122.3493° W)
- Above/below verdict against the Needle's tip (~769 ft above sea level)
- To-scale Needle gauge, preset spots, manual coordinates, mi/km toggle
- Useless stats: Space Needles laid end to end, sideways elevator time, walking time

Open `index.html` over https (e.g. GitHub Pages) so the browser allows location access.
